# Samo Ramen Humanist

The first member of the **Samo Ramen** family: a humanist typeface drawn with a
slanted broad brush nib, with Japanese signage and brush influence.

| Font | For |
| --- | --- |
| **Samo Ramen Humanist** | reading: circular bowls, soft nib |
| **Samo Ramen Humanist Display** | headings and logos: squarish bowls, firm nib |

Regular weight. Latin with the Google Fonts Latin Core character set (Western and
Central European languages), contextual alternates for a e g y f t, kerning and
combining marks.

## Files

- `fonts/ttf/`: TrueType fonts for desktop use
- `fonts/webfonts/`: WOFF2 for the web
- `sources/`: design sources (UFO), editable in a font editor
- `ofl/`: Google Fonts submission folders (fonts, METADATA, description, licence)
- `web/`: a stylesheet, fonts and demo page for using the fonts on a website

## Use on a website

Copy `web/samo-ramen.css` and `web/fonts/` into your site, link the stylesheet, and use
`font-family: "Samo Ramen Humanist"` for text and `"Samo Ramen Humanist Display"` for headings.
Only a Regular weight exists, so use `font-synthesis: none`.
